# Example index

Example 08 is the secondary identity anchor and non-diagram boundary test. Examples 02-07 validate specific composition families without overriding those roles.

For rendered runs, inspect the selected PNGs. For prompt-only runs, use the descriptions below. Apply the anchor-delta rule defined only in Step 3 of `SKILL.md`.
